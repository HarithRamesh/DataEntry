Project Setup in local system
1. Install npm (Node package manager) or nvm (node version manger) as per your convenience
2. Ensure node version to be equal to or greater that 18.18.0. node -v to check the nodeversion
3. Download postgres sql and pgadmin
4. git clone https://github.com/HarithRamesh/DataEntry.git
5. npm i
6. use "npm run start" to run the node application
7. cd react/app
8. npm i
9. use "npm start" to run the react application
